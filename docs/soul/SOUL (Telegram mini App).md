## Проблемы

**Проблемы после запуска MVP**
Продукт разрабатывался с упором на быструю сборку, в ущерб UX — многие сценарии были скопированы из других  мини-приложений без адаптации под аудиторию Soul. Это привело к  интерфейсам, не решающим ключевые задачи пользователей. 

После релиза выявились критические ошибки в логике: 

- пользователи не понимали целевого сценария приложения
- не улавливали суть игровых механик 
  В результате платформа не закрывала реальные боли аудитории и не вызывала вовлечённости.  

## Моя роль в проекте и задачи

- Исследование целевой аудитории, описание user stories для понимания потребностей пользователей  
-  пошаговый user flow, чтобы выявить разрывы в логике 
- Составление гипотез по улучшению пользовательского опыта и вовлечённости  
-  участие в исследованиях  для проверки решений и их дальнейшей интеграции в продукт  
- Работа с дизайн-системой ( исправление и обновление компонентов  для консистентности интерфейса)
