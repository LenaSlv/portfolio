# Portfolio New

Новый самостоятельный статический проект портфолио UX/UI-дизайнера.

## Структура

- `index.html` — главная страница;
- `styles.css` — адаптивные стили;
- `site.js` — интерактивность кнопки «Наверх».

## Запуск

Откройте `index.html` в браузере или запустите любой локальный статический сервер из этой папки.

Текстовые и графические заглушки в проекте можно заменить на материалы конкретного кейса.
