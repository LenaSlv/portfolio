# Коммит и push

Использовать только после явной просьбы пользователя закоммитить, запушить или опубликовать изменения. По умолчанию просьба «сделай коммит», «закоммить» или «коммит» означает: создать коммит и сразу выполнить push в настроенный upstream. Пропускать push только при явной просьбе «только коммит», «без push» или аналогичной формулировке.

Для рутинных операций коммита и push выбирать `reasoning low`, если интерфейс или конфигурация позволяют задать уровень рассуждений. Не повышать уровень без явной необходимости.

## Порядок работы

1. Проверить текущую ветку, upstream и состояние репозитория:
   `git status -sb`, `git branch --show-current`, `git remote -v`.
2. Просмотреть изменения через `git diff --stat`, `git diff --check` и `git diff`. Убедиться, что в них нет секретов, реальных данных под NDA или незапланированных правок.
3. Если есть чужие или не относящиеся к задаче изменения, не включать их в коммит и сообщить пользователю. Не использовать `git add .` и `git add -A`, если область изменений не подтверждена.
4. Добавить в индекс только файлы текущей задачи, создать понятный коммит с кратким сообщением о результате.
5. Если push не отменён явной просьбой пользователя, после успешного коммита сразу отправить его в настроенный upstream. Не использовать `--force` и `--force-with-lease` без отдельного разрешения пользователя.
6. После push снова проверить `git status -sb` и сообщить хеш коммита, ветку и результат отправки. Если пользователь явно запросил только коммит, сообщить хеш и оставить push невыполненным.

## Остановка и запрос направления

Остановиться и сообщить пользователю, если обнаружены конфликт, незапланированные файлы, провал pre-commit hook, отсутствие upstream или отклонённый push из-за новых удалённых коммитов. Не выполнять merge, rebase, reset или разрешение конфликтов без отдельного указания.

Операции, которые записывают в `.git` или обращаются к удалённому репозиторию, выполнять только с необходимыми разрешениями среды. При отказе в разрешении сообщить причину и не обходить ограничение.
