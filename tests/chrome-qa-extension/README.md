# Portfolio QA Lens

Локальное Chrome-расширение для быстрой проверки страниц портфолио.

Расширение:

- проверяет горизонтальное переполнение на текущем viewport;
- показывает элементы, которые выходят за границы экрана;
- ищет битые изображения и интерактивные элементы без подписи;
- проверяет наличие кнопки возврата наверх;
- подсвечивает найденные элементы прямо на странице;
- сохраняет скриншот текущего viewport и JSON-отчёт.
- собирает PNG и JSON одной кнопкой с общим идентификатором проверки.

Никакие данные не отправляются во внешний сервис. Отчёт можно скопировать и передать в чат вместе со скриншотом.

## Установка

1. Откройте в Chrome `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите эту папку `chrome-qa-extension`.
5. Если проверяете локальные HTML-файлы, включите для расширения «Разрешить доступ к URL файлов».

После установки откройте нужную страницу, нажмите на иконку расширения и запустите проверку. Для адаптива сначала выставьте нужный размер окна или viewport в DevTools.

Для повторного запуска изолированного QA-профиля можно выполнить из корня проекта:

```powershell
.\tests\chrome-qa-extension\open-qa-chrome.ps1 -Page case-arm-kassira.html
```

## Рабочий процесс визуальной проверки

1. Откройте страницу после правок и выставьте desktop или мобильный viewport, например `390 × 844`.
2. Откройте расширение и нажмите «Собрать комплект».
3. При проблемах нажмите «Подсветить проблемы» и повторите снимок.
4. Передайте в чат PNG и JSON с одинаковым именем. По JSON я найду технические причины, а по PNG проверю визуальное совпадение, отступы, обрезание и переполнение.
