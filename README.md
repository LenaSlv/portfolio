# Портфолио

Статический сайт-портфолио продуктового дизайнера на русском языке.

## Структура

- `index.html` — корневая страница сайта и точка входа GitHub Pages;
- `dist/` — страницы кейсов, стили, JavaScript и production-ассеты;
- `assets/` — ассеты рабочих черновиков из `docs/`;
- `docs/` — тексты кейсов, чек-листы, черновики и архивные варианты;
- `tests/chrome-qa-extension/` — расширение для визуальной проверки;
- `tests/artifacts/` — временные скриншоты, логи и профили браузера, не добавляются в Git.

## Публикация

GitHub Pages публикует `index.html` из корня репозитория. Страницы кейсов и остальные ресурсы подключаются из `dist/`.

## Проверка

После изменений HTML, CSS или JS проверить живые страницы в QA-профиле Chrome на desktop и viewport `390 × 844`. Временные результаты сохранять в `tests/artifacts/`.
